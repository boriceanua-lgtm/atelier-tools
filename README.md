# Atelier Tools v0.3.5

Noutăți în modulul Filete metrice:
- selecție material: S235/S275, S355, inox 304/316, aluminiu, alamă/bronz, fontă
- selecție tarod de așchiere sau deformare
- turație recomandată calculată din viteza de așchiere și diametrul nominal
- turația este limitată automat la 312 rpm pentru Metallkraft GS 1100-16 E
- cuplu estimat de lucru și limită inițială de protecție
- avertizare când se selectează M > 16, în afara domeniului declarat al GS 1100-16 E

Notă: cuplul este o estimare pentru setare inițială, nu o valoare garantată de producătorul tarodului.
