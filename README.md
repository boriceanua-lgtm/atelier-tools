# Atelier Tools

Aplicație PWA pentru calcule tehnice în atelier.

## Modul disponibil

- Calculator rotator de sudură
  - frecvență → rpm și mm/min
  - viteză periferică → frecvență necesară
  - timp pentru o rotație
  - setări transmisie memorate local
  - funcționare offline

## Configurație implicită

- Motor: 1320 rpm la 50 Hz
- Reductor 1: 20:1
- Reductor 2: 25:1
- Raport total: 500:1

## Publicare pe GitHub Pages

1. Încarcă toate fișierele în rădăcina repository-ului.
2. Deschide `Settings`.
3. Intră în `Pages`.
4. La `Build and deployment`, selectează `Deploy from a branch`.
5. Selectează ramura `main` și folderul `/ (root)`.
6. Apasă `Save`.
