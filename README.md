# Atelier Tools v0.3.7

## Schimbare de identitate vizuală
Paletă nouă inspirată de echipamente industriale:
- fundal antracit / aproape negru
- carduri grafit
- contururi gri-oțel
- accent portocaliu / amber industrial
- selecțiile, progresul și acțiunile principale folosesc accentul amber
- valorile-cheie din atelier, inclusiv burghiul și diametrul semifabricatului, sunt evidențiate cu amber

Funcționalitatea din v0.3.6 este păstrată.
